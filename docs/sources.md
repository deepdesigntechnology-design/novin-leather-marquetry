# منابع و مراجع

## استاندارد رسمی

- استاندارد شغل معرق‌کار چرم
- کد: ۱-۰۲-۰۰-۷۷-۶۵۳۷

## متون پایه پروژه

- کتاب آموزشی صنعت نوین معرق چرم (متون فیکس‌شده)
- تقدیم‌نامه و مقدمه نهایی
- تعاریف فیکس‌شده اصطلاحات تخصصی
- ساختار قطعی ۸ فصلی + ساختار ۱۰ بخشی هر فصل

## پدیدآورنده شیوه

استاد افشین خلیلی

## گروه

گروه خلاقیت‌های تجسمی ایده — عرصه سیمرغ — اصفهان

## یادداشت

محتوای این وب‌سایت بر اساس دانش تثبیت‌شده پروژه آموزشی تدوین شده و با اصطلاحات فیکس‌شده پروژه منطبق است.
