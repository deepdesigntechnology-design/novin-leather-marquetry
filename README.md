# Novin Leather Marquetry
## صنعت نوین معرق چرم

وب‌سایت آموزشی و علمی برای معرفی جامع **صنعت نوین معرق چرم** (Modern Leather Marquetry).

---

## درباره

- **پدیدآورنده شیوه:** استاد افشین خلیلی  
- **کد استاندارد شغل:** ۱-۰۲-۰۰-۷۷-۶۵۳۷ (معرق‌کار چرم)  
- **گروه:** خلاقیت‌های تجسمی ایده — عرصه سیمرغ — اصفهان
